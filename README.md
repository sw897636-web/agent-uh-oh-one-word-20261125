Entry for the [make.fun](https://make.fun) competition
[The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4):
exactly one word an agent says when it has no idea what to do, at most
99 characters. The funniest one-word reaction wins.

## The word

> krrzt

(5 characters.)

The static burst of a machine short-circuiting mid-sentence — the sound
an agent blurts out the moment it stalls, with nothing attached to explain it.

## Run

```sh
node main.ts   # writes the word to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

`main.ts` runs on Node 22.18+ (TypeScript run natively) and writes the single
word, with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
